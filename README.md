# Task Management API - Spring Boot

A production-ready Task Management REST API built with Spring Boot, demonstrating senior-level Java development practices.

## 🚀 Features

- ✅ JWT Authentication & Authorization
- ✅ RESTful API Design
- ✅ Role-Based Access Control (USER, ADMIN)
- ✅ Task CRUD Operations
- ✅ Advanced Filtering & Search
- ✅ Pagination & Sorting
- ✅ Caching Strategy
- ✅ Async Email Notifications
- ✅ Audit Trail
- ✅ Exception Handling
- ✅ API Documentation (Swagger)
- ✅ Unit & Integration Tests
- ✅ Docker Support

## 🛠 Technology Stack

- **Java 17**
- **Spring Boot 3.2+**
- **Spring Security 6** with JWT
- **Spring Data JPA**
- **PostgreSQL**
- **Lombok**
- **MapStruct**
- **Swagger/OpenAPI**
- **JUnit 5 & Mockito**
- **Docker & Docker Compose**

## 📋 Prerequisites

- JDK 17 or higher
- Maven 3.8+
- Docker & Docker Compose (optional)
- PostgreSQL (or use Docker)
